# tools

## logdigest.py — сводка по логам поездки

Сжимает архив логов Headswap в дайджест на 40–80 строк: окружение, таблица сессий,
обрывы, fps, ошибки, AUTOSRV, звук и микрофон, навигация, тач. Только stdlib Python 3.

```
python -X utf8 tools/logdigest.py <архив.zip | папка | файл.log> [--json]
```

Вход:
- zip из приложения («Поделиться отчётом»/«Сохранить архив»): `device.txt` + `logs/headswap-*.log`
  (в старых версиях `probe-*.log`), логи обрезаны до последних 4 МиБ;
- папка с полными логами, снятыми через adb (ищется рекурсивно, `logcat-*.txt` тоже подхватывается);
- отдельный `.log`.

`--json` выдаёт те же данные структурой, текст строится из неё же.

Что в разделах и откуда:
1. **Окружение** — `device.txt`; ГУ только из `HU_INFO` (строка `аксессуар:` — всегда Baidu CarLife, это не ГУ).
2. **Сессии** — от `== USB_ACCESSORY_ATTACHED` / `сессия: старт` до `== РЕЗЮМЕ СЕССИИ`; длительность и причина
   из резюме. `~` у времени начала — сессия началась до обрезки лога (время оценено). «лог кончился» — резюме нет.
   Колонка AA — главная AA-сессия (`AA итог`, наибольшее data), в скобках сколько их было (обычно вторая —
   короткая заглушка «мост остановлен»).
3. **Обрывы** — EOF, EIO/ENODEV, BYEBYE_REQUEST, USB_ACCESSORY_DETACHED, peer closed, POWER_DISCONNECTED
   из logcat («зажигание»); события в пределах 15 с склеены в эпизод. Флаг «без GMS» — EOF за ≤5 с после
   MEDIA_START (не MEDIA_PLAYBACK) при config=0 и 0 видеокадров.
4. **Видео** — `BRIDGE видео[...]` и `видео: отправлено ... (+N за 5с)`; интервалы вне 3–15 с отброшены.
5. **Ошибки** — `ERROR` и строки с `Exception`, цифры нормализованы.
6–9. AUTOSRV, звук/микрофон (`MIC_REQUEST` на NAVIGATION(10) — не микрофон), навигация (0x18043/0x18045,
   NAVI_NEXT_TURN_INFO), тач.

Дальше скаут грепает лог только в окнах вокруг времён из дайджеста.

Тест: `python -X utf8 -m unittest tools/test_logdigest.py`
